# Meteor artwork

## Plugin icon

`meteor-icon.png` is the unmodified Meteor organization avatar, retrieved on
2026-11-10 from https://avatars.githubusercontent.com/u/789528?v=4.
The source organization is https://github.com/meteor.

The image is 298 x 298 pixels. It works for repository plugin presentation.
For a directory that requires at least 512 x 512 pixels, obtain an approved
larger original before submission. Do not upscale or redraw the logo and
present that as new approved artwork.

## Repository and social banner

[`meteor-ai-skills-banner.png`](./meteor-ai-skills-banner.png) is the 1672 x 941
Meteor AI Skills banner used in the repository README and social announcements.
The README banner links to the installation section.

The image shows the short, unpinned `npx skills add meteor/agent-skills`
command. The [installation guide](../README.md#install) provides a pinned
installer for compatibility with the Node versions used by Meteor 3.
