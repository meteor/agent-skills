# Meteor plugin artwork

`meteor-icon.png` is the unmodified Meteor organization avatar, retrieved on
2026-11-10 from https://avatars.githubusercontent.com/u/789528?v=4.
The source organization is https://github.com/meteor.

The image is 298 x 298 pixels. It works for repository plugin presentation.
For a directory that requires at least 512 x 512 pixels, obtain an approved
larger original before submission. Do not upscale or redraw the logo and
present that as new approved artwork.
