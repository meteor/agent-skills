## Uncertain findings

U01: The Rspack guide broadly says asynchronous server startup completes before
tests. The active TLA fixture proves awaited module dependencies, but its
`server/async-startup.app-test.js` suite uses `describe.skip` for an asynchronous
`Meteor.startup` callback. Do not turn this into a universal guarantee that
every driver awaits every startup callback, timer or detached Promise. A driver
version-specific active regression would resolve the broader claim. Apply only
the verified module-level TLA portion of F04.

## No-action findings

- `meteor-node-stubs@1.2.30` bundles patched `qs@6.16.0`. Record this security
  dependency refresh in the release handoff; it introduces no new application
  API or reason for a new skill. A core update alone does not prove an app's
  npm lockfile changed.
- Manifest hashes/SRI now match final file bytes; the fix does not justify
  teaching application developers to rewrite generated manifest data.
- Cordova local plugin URL/path preservation is a framework fix, not a reason
  to teach manual URL decoding or rewrite valid plugin paths.
- WebApp HTML attribute hook documentation and corrected boilerplate examples
  do not conflict with a current distributable example. No new WebApp skill is
  authorized by this request.
- `Meteor.user()` may return `undefined` before the document reaches Minimongo;
  the post-tag change documents existing behavior. Do not label it as a new
  3.5.2 runtime change.
- Internal tools-core helpers, native test infrastructure, CI health checks,
  release automation, and core maintainer skills remain outside the catalog.
