### Verified pinned update commands

Codex rejects adding the same marketplace name with a different ref until
its previous registration is removed. This changes the marketplace pin:

```bash
codex plugin marketplace remove meteor
codex plugin marketplace add meteor/agent-skills --ref v1.1.0-beta.4
codex plugin add meteor@meteor
```

Claude Code accepts replacing the source. Match the existing install scope:

```bash
claude plugin marketplace add meteor/agent-skills#v1.1.0-beta.4 --scope local
claude plugin update meteor@meteor --scope local
```

Skills CLI selected and full-catalog checks used these non-interactive forms
of the pinned repository command:

```bash
npx skills@latest add 'meteor/agent-skills#v1.1.0-beta.4' --skill meteor-mongo-minimongo --agent codex --copy --yes
npx skills@latest add 'meteor/agent-skills#v1.1.0-beta.4' --all --agent codex --copy --yes
```

Restart the client after installing or updating.
