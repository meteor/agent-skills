# Meteor Agent Skills 1.1.2

This catalog patch ships Cordova deployment and migration guidance for Meteor 3.6.1 and the 3.5.5 and 3.4.4 backports. It was published independently of the framework. For each affected app, the skills link to its release-specific Cordova heading in the public Meteor source. [Release](https://github.com/meteor/agent-skills/releases/tag/v1.1.2) · [Change and review](https://github.com/meteor/agent-skills/pull/47).
