# Meteor Agent Skills 1.1.1

## Candidate and scope

Stable patch preparation for the 17-skill catalog. Twelve existing skills
receive corrections for the already published Meteor 3.6.1, 3.5.5 and 3.4.4
security releases. No new skills, package dependencies, plugin layout or
installation mechanisms are introduced.

```text
Content candidate: 1065aa7a003db01807c7e441d30eab9a291ef006
Version and policy preparation: 6b5942612018ff14dc33e3415058a18422b727cf
Release PR: https://github.com/meteor/agent-skills/pull/45
Planned catalog version: 1.1.1
Planned tag: v1.1.1
```

The owner requested direct stable publication after verification and accepted
maintainer-run review. The updated publishing policy selects beta testing by
changed distribution/compatibility behavior rather than requiring it for every
guidance correction. Exact candidate checks and observed failures remain release
gates. No beta or outside-contributor acceptance is claimed.

This is an independent catalog follow-up to released Meteor versions. It does
not publish or modify a Meteor framework release. The [candidate reconciliation](../../audits/skill-gaps/2026-11-13-agent-skills-1.1.1-candidate.md)
pins the source revisions and links the [original audit](../../audits/skill-gaps/2026-11-13-meteor-security-releases.md).
The [implementation record](../maintenance/2026-11-13-security-release-update.md)
retains the earlier authoring and simplification evidence.

## Limits

Checks cover guidance, repository tools and Linux client distribution. They do
not establish live OAuth-provider behavior, native-device execution, production
database performance or a complete Meteor runtime regression run. Marketplace
directory submission and announcements are separate work.
