there is no separate beta skill. The review also records stable 3.6 cleanup.

[CI run 36605798565](https://github.com/meteor/agent-skills/actions/runs/36605798565)

`fast-uri@3.1.6` override used by AJV. Commit `ec87223` raises only that
override and its lockfile resolution to 3.1.7; it does not weaken the audit
threshold or change distributed skill content. The next candidate CI passed.
