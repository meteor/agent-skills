official Meteor 3.6 and preserve earlier supported framework and package
branches. Their contents are unchanged from the verified beta.4.

## Verification baseline

The [beta.4 handoff](v1.1.0-beta.4.md) preserves the 30-case acceptance run,
downloaded archive comparisons, isolated client installations and installed
discovery results. Skills CLI instructions now use `npx skills add`, with
Node 22.20.0+ required by the installer and `skills@1.5.18` retained as the
older-Node fallback. Application runtime requirements remain independent.

The preparation passed 43 automated tests and seven public installation jobs.
They cover the unpinned command on Node 22.20.0, 24 and 26, explicit latest on
Node 22.20.0, and the fallback on Node 20.15.1, 20.16.0 and 22.11.0. Updated
release-publishing case 9 passed in a fresh supplied-text conversation with
hidden criteria and tools disabled.
