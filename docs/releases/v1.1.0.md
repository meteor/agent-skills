# 1.1.0 release handoff

[Meteor Agent Skills v1.1.0](https://github.com/meteor/agent-skills/releases/tag/v1.1.0)
is the first stable catalog, published November 10, 2026. Its 17 skills
consolidate official Meteor 3.6 and preserve earlier supported framework and
package branches. Skill contents are unchanged from the verified beta.4.

## Installation

Use Node.js 22.20.0+ in the installation shell:

```bash
npx skills add 'meteor/agent-skills#v1.1.0'
```

For Node 20 or early Node 22:

```bash
npx skills@1.5.18 add 'meteor/agent-skills#v1.1.0'
```

The installer requirement does not change an application's runtime. The
current default/latest installer fails on Node 20 before reading the catalog.
For all published skills, append `--agent codex --yes`; avoid `--all` with
1.5.18 because it also includes maintainer skills and all agents. Plugin
installation and verified upgrade commands are in the [README](../../README.md#install)
and [release notes](https://github.com/meteor/agent-skills/releases/tag/v1.1.0).
